yaozarrs.write.v06#

Functions to write OME-Zarr v0.6 stores from yaozarrs.v06 models. See Writing OME-Zarr for how to use them.

Things that are specific to v0.6#

  • dimension_names are still written. v0.5 required each array's zarr.json to include dimension_names matching the axes. v0.6 no longer requires it, but other Zarr tools find it useful, so yaozarrs still writes them, using the axis names of the multiscale's "intrinsic" coordinate system.
  • No transformation is added between an image and its labels. Without one, a label image is usually understood to share the image's intrinsic coordinate system. If it doesn't (e.g. your labels were written for a crop of the image, with the crop's corner as their origin), add a transformation to the image's Multiscale.coordinateTransformations (see Lining labels up with the image).
  • The scene metadata is written as given. Unlike plate metadata, which write_plate can generate for you, a Scene says how your images relate to each other, so you write it yourself. write_scene checks it against the images (and their labels) before anything is written: every image it refers to must be there, with the coordinate systems it names, and the scene's transformations must connect them all. (A reference to a label image you don't pass in isn't checked, and neither is the graph, in that case.)
  • Transformation parameters stored in Zarr aren't written for you. An affine or rotation may keep its matrix in a Zarr array (referenced by path) instead of in the JSON, and displacements and coordinates always keep their vector field in a separate multiscale image group. If you use those, write that data yourself (for a scene, the spec recommends a group called coordinateTransformations, next to the images).

LabelsBuilder(
    dest: str | PathLike,
    *,
    writer: ZarrWriter = "auto",
    chunks: ShapeLike | Literal["auto"] | None = "auto",
    shards: ShapeLike | None = None,
    overwrite: bool = False,
    compression: CompressionName = "blosc-zstd",

Builder for labels groups within an Image.

The labels group structure includes: - A labels group with LabelsGroup metadata listing all label names - Each label as a separate LabelImage subgroup (e.g., cells/, nuclei/)

This builder supports two workflows:

  1. Immediate write (simpler): Use write_label() to write each label with its data immediately. The builder auto-generates and updates LabelsGroup metadata after each call.

  2. Prepare-only (flexible): Use add_label() to register all labels, then prepare() to create the hierarchy with empty arrays. Write data to the returned array handles yourself.

See Also
  • write_image : High-level function with labels parameter for writing everything at once.

def prepare(self) -> tuple[Path, dict[str, Any]]:
    """Create the Zarr hierarchy and return array handles.

    Creates the complete labels group structure including LabelsGroup
    metadata, and empty arrays for all registered labels. Call this after
    registering all labels with `add_label()`.

    The returned arrays support numpy-style indexing for writing data:
    `arrays["label_name/dataset"][:] = data`.

    Returns
    -------
    tuple[Path, dict[str, Any]]
        A tuple of (root_path, arrays) where `arrays` maps composite keys
        like `"cells/0"` (label name / dataset path) to array objects. The
        array type depends on the configured writer (zarr.Array or
        tensorstore.TensorStore).

    Raises
    ------
    ValueError
        If no labels have been added with `add_label()`.
    FileExistsError
        If destination exists and `overwrite` is False.
    ImportError
        If no suitable writer backend is installed.
    """
    if not self._labels:  # pragma: no cover
        raise ValueError("No labels added. Use add_label() before prepare().")

    labels_group = self._labels_group_type(labels=self._all_labels(self._labels))
    # (an existing labels group is added to, not replaced)
    if (self._dest / "zarr.json").exists():
        _update_zarr3_group(self._dest, labels_group)
    else:
        _create_zarr3_group(self._dest, labels_group, self._overwrite)

    all_arrays: dict[str, Any] = {}
    for label_name, (label_image, datasets) in self._labels.items():
        all_arrays.update(self._prepare(label_image, datasets, label_name))
    return self._dest, all_arrays

Builder for OME-Zarr v0.6 Plate hierarchies with auto-generated metadata.

The Plate hierarchy includes: - A root Plate group with metadata (auto-generated from written wells) - Well subgroups (e.g., A/1/, B/2/, etc...) each containing Well metadata - Field subgroups (e.g., 0/, 1/) within each well, each an Image

This builder supports two workflows:

  1. Immediate write (simpler): Use write_well() to write each well with its field data immediately. The builder auto-generates and updates plate metadata (rows, columns, wells) after each call, similar to how Bf2RawBuilder auto-updates the series list.

  2. Prepare-only (flexible): Use add_well() to register all wells, then prepare() to create the hierarchy with empty arrays. Plate metadata is auto-generated from all registered wells.

See Also

def write_well(
    self,
    row: str,
    col: str,
    images: Mapping[str, ImageWithDatasets[Image]],
    *,
    progress: bool = False,
) -> Self:
    """Write a well immediately with its `images` (fields of view) and data.

    This method creates the well structure and writes all field data in one
    call. The plate structure and well metadata are created/updated
    automatically. Plate metadata (rows, columns, wells) is auto-generated
    from all written wells and rewritten after each call.

    Parameters
    ----------
    row : str
        Row name like "A", "B", etc.
    col : str
        Column name like "1", "2", etc.
    images : Mapping[str, ImageWithDatasets]
        Mapping of `{fov -> (image_model, datasets)}` where:
        - fov: Field of view identifier like "0", "1", etc.
        - datasets can be:
          - Single array (for one dataset): `{"0": (image, data)}`
          - Sequence (for multiple datasets): `{"0": (image, [data1, data2])}`
    progress : bool, optional
        Show progress bar for dask arrays. Default is False.

    Returns
    -------
    Self
        The builder instance (for method chaining).

    Raises
    ------
    ValueError
        If row/col combination was already written or added, or if a user-
        provided Plate doesn't include this well.
    NotImplementedError
        If any Image has multiple multiscales.
    """
    self._validate_well_coordinates(row, col)
    normalized_fields = self._check_fields(row, col, images)
    # (after the checks, so nothing is created for a well that would be rejected)
    self._ensure_initialized()

    self._written_wells_data[(row, col)] = cast(
        "dict[str, ImageWithDatasets]", normalized_fields
    )
    self._update_plate_metadata()

    well_path = f"{row}/{col}"
    self._create_well_group(well_path, list(images))
    for fov, (image_model, datasets_seq) in normalized_fields.items():
        self._write(image_model, datasets_seq, well_path, fov, progress=progress)
    return self

def prepare(self) -> tuple[Path, dict[str, Any]]:
    """Create the Zarr hierarchy and return array handles.

    Checks the scene against all its images (those added with `add_image()` and
    any already written with `write_image()`), then creates the scene group and
    empty arrays for every added image.

    Returns
    -------
    tuple[Path, dict[str, Any]]
        A tuple of (root_path, arrays) where `arrays` maps composite keys
        like `"tile_0/0"` (image path / dataset path) to array objects, and
        `"tile_0/labels/cells/0"` for label images. The array type depends on
        the configured writer (zarr.Array or tensorstore.TensorStore).

    Raises
    ------
    ValueError
        If no images have been added with `add_image()`, if the scene
        references an image (or coordinate system) that isn't there, or if
        its coordinate systems aren't all connected.
    FileExistsError
        If destination exists and `overwrite` is False.
    ImportError
        If no suitable writer backend is installed.
    """
    if not self._images:
        raise ValueError("No images added. Use add_image() before prepare().")
    added: dict[str, Image] = {}
    for path, (image, _, _, labels) in self._images.items():
        added[path] = image
        added.update(_label_paths(path, labels))
    _check_scene(
        self._scene, {**self._written_images, **self._written_labels, **added}
    )

    self._ensure_initialized()
    all_arrays: dict[str, Any] = {}
    for path, (image, specs, options, labels) in self._images.items():
        _ensure_parent_groups(self._dest, path)
        all_arrays.update(self._prepare(image, specs, path, **options))
        if labels:
            builder = LabelsBuilder(
                self._dest / path / "labels",
                writer=self._writer,
                overwrite=self._overwrite,
                **options,
            )
            for name, (label_image, label_specs) in labels.items():
                builder.add_label(name, label_image, label_specs)
            for key, arr in builder.prepare()[1].items():
                all_arrays[f"{path}/labels/{key}"] = arr
    return self._dest, all_arrays

def write_scene(
    dest: str | PathLike,
    scene: Scene,
    images: Mapping[str, ImageWithDatasets],
    *,
    labels: Mapping[str, LabelsWithDatasets] | None = None,
    extra_attributes: dict[str, Any] | None = None,
    writer: ZarrWriter = "auto",
    overwrite: bool = False,
    chunks: tuple[int, ...] | Literal["auto"] | None = "auto",
    shards: tuple[int, ...] | None = None,
    compression: CompressionName = "blosc-zstd",
    progress: bool = False,
) -> Path:
    """Write an OME-Zarr v0.6 scene: images that share a spatial relationship.

    The scene group holds the [`Scene`][yaozarrs.v06.Scene] metadata (transformations
    between the coordinate systems of its images, and optionally coordinate systems
    of its own), and each image is written as a subgroup at its path:

        dest/
        ├── zarr.json          # attributes["ome"]["scene"]
        ├── tile_0/            # images["tile_0"]
        │   ├── zarr.json      # Image metadata
        │   └── 0/             # dataset arrays
        └── tile_1/
            └── ...

    Before anything is written, the scene's references are checked: every
    transformation `input`/`output` with a `path` must name one of `images`, with a
    coordinate system of that `name`, the transformation's dimensions must fit the
    coordinate systems it links, and the coordinate systems of the scene and its
    images must form one connected graph.  Label images given in `labels` are checked
    (and can be referenced) like the images.  A reference to any other multiscale
    image *inside* one of `images` (such as a label image you write afterwards with a
    [`LabelsBuilder`][yaozarrs.write.v06.LabelsBuilder]) is allowed, but not checked,
    as that image isn't written here; nor is the graph, in that case.

    `chunks`, `shards` and `compression` apply to every image.  If the images have
    different numbers of dimensions, use `chunks="auto"` (the default) or `None`, or
    write them with a [`SceneBuilder`][yaozarrs.write.v06.SceneBuilder], which takes
    these settings per image.

    With `overwrite=True`, an existing store at `dest` is replaced once the checks pass.

    Transformation parameters stored in Zarr arrays (e.g. an `affine` with a `path`)
    are not written by this function: write them below `dest` afterwards (the spec
    recommends a `coordinateTransformations` group).

    See Also
    --------
    - [`SceneBuilder`][yaozarrs.write.v06.SceneBuilder] : Builder class for
      incremental image writing.
    - [`write_image`][yaozarrs.write.v06.write_image] : Write a single Image group.

    Parameters
    ----------
    dest : str | PathLike
        Destination path for the scene Zarr group.
    scene : Scene
        OME-Zarr Scene metadata model.
    images : Mapping[str, ImageWithDatasets]
        Mapping of `{path -> (image_model, [datasets, ...])}`.  Each path (e.g.
        "tile_0", or "tiles/0") becomes an Image subgroup of the scene group.
    labels : Mapping[str, Mapping[str, tuple[LabelImage, ArrayOrPyramid]]] | None
        Label images to write alongside the images, as `{image path -> {label name ->
        (LabelImage, datasets)}}` (see `write_image`).  Each one is written to
        `dest/{image path}/labels/{label name}/`, and the scene may refer to it there.
        Default is None.
    extra_attributes : dict[str, Any] | None, optional
        Additional attributes to write alongside "ome" in the scene's zarr.json.
    writer : "zarr" | "tensorstore" | "auto" | CreateArrayFunc, optional
        Backend to use for writing arrays. Default is "auto".
    overwrite : bool, optional
        If True, overwrite existing Zarr groups. Default is False.
    chunks : tuple[int, ...] | "auto" | None, optional
        Chunk shape for all arrays. See `write_image` for details.
    shards : tuple[int, ...] | None, optional
        Shard shape for Zarr v3 sharding. Default is None (no sharding).
        When present, shard_shape must be divisible by chunk shape.
    compression : "blosc-zstd" | "blosc-lz4" | "zstd" | "none", optional
        Compression codec. Default is "blosc-zstd".
    progress : bool, optional
        Show progress bar when writing dask arrays. Default is False.

    Returns
    -------
    Path
        Path to the scene Zarr group.

    Raises
    ------
    TypeError
        If given a model from another OME-Zarr version (e.g. a v05.Image).
    ValueError
        If the scene references an image (or coordinate system) that isn't in
        `images`, if its coordinate systems aren't all connected, if any image (or
        label image) has mismatched datasets/metadata, or if `labels` names an image
        that isn't in `images`.
    NotImplementedError
        If any Image has multiple multiscales.
    FileExistsError
        If `dest` exists and `overwrite` is False.
    ImportError
        If no suitable writer backend is installed.

    Examples
    --------
    Two tiles, placed side by side in a "world" coordinate system:

    >>> import numpy as np
    >>> from yaozarrs import DimSpec, v06
    >>> from yaozarrs.write.v06 import write_scene
    >>>
    >>> def make_image():
    ...     dims = [
    ...         DimSpec(name="y", scale=0.5, unit="micrometer"),
    ...         DimSpec(name="x", scale=0.5, unit="micrometer"),
    ...     ]
    ...     return v06.Image(multiscales=[v06.Multiscale.from_dims(dims)])
    >>>
    >>> world = v06.CoordinateSystem(
    ...     name="world",
    ...     axes=[
    ...         v06.SpaceAxis(name="y", unit="micrometer"),
    ...         v06.SpaceAxis(name="x", unit="micrometer"),
    ...     ],
    ... )
    >>> scene = v06.Scene(
    ...     scene=v06.SceneDef(
    ...         coordinateSystems=[world],
    ...         coordinateTransformations=[
    ...             v06.TranslationTransformation(
    ...                 translation=[0, 32 * i],
    ...                 input={"path": f"tile_{i}", "name": "intrinsic"},
    ...                 output={"name": "world"},
    ...             )
    ...             for i in range(2)
    ...         ],
    ...     )
    ... )
    >>> images = {
    ...     f"tile_{i}": (make_image(), np.zeros((64, 64), dtype=np.uint16))
    ...     for i in range(2)
    ... }
    >>> result = write_scene("my_scene.zarr", scene, images)
    >>> (result / "tile_1" / "zarr.json").exists()
    True
    """
    builder = SceneBuilder(
        dest,
        scene,
        extra_attributes=extra_attributes,
        writer=writer,
        chunks=chunks,
        shards=shards,
        overwrite=overwrite,
        compression=compression,
    )
    labels = labels or {}
    if unknown := sorted(set(labels) - set(images)):
        raise ValueError(
            f"labels: {unknown} are not among the scene's images ({sorted(images)})"
        )
    # (check everything first, so a bad image doesn't leave a partial scene behind)
    seen: list[str] = []
    for path, (image_model, datasets) in images.items():
        builder._check_image(
            path, image_model, datasets, others=seen, labels=labels.get(path)
        )
        seen.append(path)
    all_images: dict[str, Image] = {}
    for path, (image, _) in images.items():
        all_images[path] = image
        all_images.update(_label_paths(path, labels.get(path)))
    _check_scene(scene, all_images)

    builder._ensure_initialized()
    for path, (image_model, datasets) in images.items():
        builder.write_image(
            path, image_model, datasets, labels=labels.get(path), progress=progress
        )

    return builder.root_path
