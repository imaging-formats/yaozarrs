YZ-MS-005: multiscale-transforms-follow-dataset-rules#

Transformations in multiscales coordinateTransformations must follow the same rules (allowed types, order, etc.) as those of datasets.
Spec level MUST
yaozarrs severity error
Status stable
Spec versions 0.4 to 0.6
Reported by yaozarrs in —

Notes#

yaozarrs validates them with the same validator as dataset transformations, so violations report YZ-DS-009 and YZ-CT-001 to YZ-CT-004, not this code. In 0.6, multiscale transformations have their own constraints (YZ-CT-012, YZ-CT-013, YZ-CT-014).

Spec text#

0.5#

Each "multiscales" dictionary MAY contain the field "coordinateTransformations", describing transformations that are applied to all resolution levels in the same manner. The transformations MUST follow the same rules about allowed types, order, etc. as in "datasets:coordinateTransformations" and are applied after them.

ome/ngff-spec@0.5 · index.md L317-L318

0.4#

Each "multiscales" dictionary MAY contain the field "coordinateTransformations", describing transformations that are applied to all resolution levels in the same manner. The transformations MUST follow the same rules about allowed types, order, etc. as in "datasets:coordinateTransformations" and are applied after them.

ome/ngff-spec@0.4 · index.md L383-L384
